## ai-code-review-action v1.0.0

First release. Reviews every pull request with Claude and posts one review.

### What it does

- Reviews on `pull_request` (`opened`, `synchronize`, `reopened`) and on a `/ai-review` comment. Fork PRs are skipped on `pull_request` because they get no secrets and a read-only token.
- Fetches changed files with `pulls.listFiles`, skips lock files, binaries, generated output and `ignore` globs, and stops at `max_files`.
- Parses every unified diff itself and anchors inline comments only on added lines, with the exact new-file line number.
- Shows up to 30 lines of the head-revision file around each hunk as labelled context.
- Measures every request with `messages.countTokens` and batches files under `max_diff_tokens`; the stable system prompt is cached with `cache_control: ephemeral` across batches.
- Calls Claude Opus 5.5 through `messages.parse` with a zod schema; `stop_reason` is checked before output, and a refusal or `max_tokens` becomes a "could not complete" note with exit code 0.
- Validates every finding against the diff; findings that cannot be placed become file-level notes in the review body.
- Posts exactly one review: inline comments with GitHub suggestion blocks, a severity table, the verdict, token usage and estimated cost. `REQUEST_CHANGES` and a failed check when `fail_on` is met.
- Idempotent across pushes: earlier bot reviews are dismissed or collapsed, and a finding already on the PR is never posted twice.
- `LLM_PROVIDER=mock` runs the whole pipeline without an API key.

### Inputs

`anthropic_api_key` (required), `github_token`, `model` (default `claude-opus-5-5`), `config_path` (default `.github/ai-review.yml`), `fail_on` (default `none`), `max_files` (default `40`), `max_diff_tokens` (default `60000`).

### Config file

`ignore`, `focus`, `style_comments`, `language`, `max_findings`, `effort`, `context_lines`. See the README for the reference table.

### Quality

- 71 vitest tests, including an end-to-end run against recorded GitHub API fixtures.
- `pnpm eval` scores the reviewer on 12 planted-bug diffs plus one clean diff and writes `docs/eval-results.md`.
- CI fails when `dist/` is out of date.
